# Netflix Data Analysis Using Python

## Internship Project – Auspify Technologies

### Project Overview
This project focuses on analysing Netflix movies and TV shows using Python. The analysis includes data cleaning, content type analysis, country-wise analysis, and release-year trend analysis.

### Objectives
- Clean and prepare the Netflix dataset.
- Analyse Movies and TV Shows distribution.
- Identify countries with the highest Netflix content representation.
- Study content distribution across release years.
- Generate visualisations and business insights.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

### Tasks Completed

**Task 1: Netflix Data Cleaning & Preparation**
- Standardised dataset columns.
- Checked missing values and duplicates.
- Prepared the cleaned dataset.

**Task 2: Content Type Analysis**
- Analysed Movies and TV Shows.
- Created bar and pie charts.
- Found that Movies represent 69.69% and TV Shows 30.31%.

**Task 3: Country-Wise Content Analysis**
- Analysed country-wise Netflix content entries.
- Identified the United States as the leading country, followed by India and the United Kingdom.

**Task 4: Release Year Trend Analysis**
- Analysed 8,790 titles across release years.
- Identified 2018 as the peak year with 1,146 titles.

The project demonstrates how Python can be used to clean, analyse, and visualise Netflix content data to discover meaningful patterns and business insights.
